# Riqor v0.2.5

## Plugin Directory moderation hotfix

This release removes `security-penetration-tester` from the public ChatGPT/Codex Plugin after Plugin Directory review flagged it for cyber-abuse, fraud/scam, and security-risk concerns

- preserves the canonical repository agent source for internal development use
- removes the generated public Skill and its instruction reference
- removes the distributed native Codex agent copy and profile registration
- removes the specialist from `agent-skill-map.json` and the generated routing index
- adds a generator-level public exclusion so regeneration cannot restore the rejected capability
- updates the public plugin to 100 generated specialist pairs plus 11 workflow Skills, for 111 bundled Skills total
- changes no Apps or MCP configuration and keeps the existing privacy/support boundaries

## Verification intent

The release gate requires the generated catalog check, plugin health, deterministic ZIP packaging, full repository tests, packaged npm runtime tests, action-pin verification, backlog checks, and release preflight. The final plugin ZIP must contain no `security-penetration-tester` path or registration
