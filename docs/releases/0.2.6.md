# Riqor v0.2.6

## Generic ChatGPT/Codex Plugin Autopilot

This release adds `chatgpt-codex-plugin-autopilot`, a repo-agnostic operational Skill for taking an arbitrary repository from plugin inspection through validated publication and post-publish verification

- refreshes the current official OpenAI Plugin and Skill contract before public configuration work
- detects Skills-only, MCP-backed, and hybrid plugin architectures
- inspects and repairs manifest, Skills, optional MCP/app configuration, hooks, branding, legal/support URLs, and release metadata
- applies final-directory metadata and archive constraints with dependency-free Python tooling
- builds deterministic archive-root ZIPs and records SHA256 evidence
- diagnoses uploader and review failures by root cause
- supports Full Autopilot Publish with fail-closed gates and remote artifact verification

## Public-distribution safety

- preserves the existing `security-penetration-tester` public exclusion added in v0.2.5
- validates exclusion slugs against public paths and UTF-8 text so generated copies, registrations, maps, indexes, or archive entries cannot silently return
- keeps the public plugin at 100 safe generated specialist pairs plus 12 workflow Skills, for 112 bundled Skills total
- adds no MCP server or ChatGPT app to Riqor itself

## Listing hardening

- shortens the public short description to the current final-directory limit
- validates listing lengths, category, starter prompts, branding contrast, square assets, component paths, Skill identity/body constraints, archive depth, normalization, secret-shaped files, and deterministic package size
