# Riqor v0.2.0-beta.3

Release date: 2026-08-09
Channel: Beta prerelease

## What changed

- Renamed the public Codex plugin identity and repository marketplace from the legacy `codex-self-improvement` name to `riqor`
- Added the complete Riqor skill pack to the Codex plugin, including setup, core operation, evidence, managed Codex, diagnostics, security, and release workflows
- Made plugin lifecycle hooks runnable with Node 22 so Marketplace users do not need Bun for the installed plugin
- Enforced terminal-only npm publishing and removed npm provenance configuration that requires cloud CI
- Made the GitHub tag workflow fetch the published npm tarball, verify byte identity against the release build, and attach the registry artifact
- Added workflow regression checks that reject npm publish commands or npm publish credentials in GitHub Actions

## Release contract

- npm package: `riqor@0.2.0-beta.3` on the `beta` dist-tag
- Codex plugin: `riqor@riqor`
- Marketplace source: `imMamdouhaboammar/riqor`
- Git tag: `v0.2.0-beta.3`
- npm publication is performed from the authenticated local terminal only

## Verification

The release is publishable only after the full repository gate, plugin validator, clean Marketplace install smoke test, registry install smoke test, and post-publish npm/GitHub artifact checks succeed. Machine-readable post-publish evidence is recorded in [`0.2.0-beta.3-verification.json`](0.2.0-beta.3-verification.json).
