# Riqor v0.2.0-beta.1

Released: 2026-08-09
Channel: Beta prerelease

`0.2.0-beta.1` is the first Riqor beta release. It is published to the npm `beta` dist-tag and must not replace the stable `latest` tag.

## Install the beta

```bash
npx riqor@beta install
```

Confirm the installed version:

```bash
riqor version --json
riqor doctor --package-only --json
```

## What changed

- Added managed Google Antigravity (`agy` or `antigravity`) sessions alongside managed Codex sessions
- Added a canonical six-skill Riqor Skills Pack and bundled it into the npm runtime with provenance coverage
- Added focused repository analysis, goal-loop, schema-fuzzing, evidence-pack, review, task-plan, and convergence capabilities
- Made swarm locking atomic under real concurrent acquisition and made task-ledger mutations honor lock ownership
- Hardened destructive-command detection against alternate `rm` flag forms and destructive `git reset --hard` targets
- Changed trajectory export to require real caller-provided events instead of emitting synthetic sample data
- Corrected full doctor semantics so Codex and AGY are alternatives and Kaku is optional
- Corrected package security diagnostics so they scan the Riqor package instead of the caller repository
- Removed transient planning, evaluation, and generated graph artifacts from the public repository surface
- Added prerelease-aware npm and GitHub release automation

## Beta boundaries

This release does not move npm `latest` and does not publish a new Homebrew formula. The stable `0.1.x` line remains the default stable channel.

Riqor remains local developer tooling. It does not attach to unrelated agent sessions, does not install a network listener, and does not persist prompts, transcripts, source contents, raw command output, environment values, credentials, cookies, or tokens in its bounded run and activator state.

## Release verification

The release tag is created only after the complete repository, package, security, package-inspection, action-pin, and review gates pass. Post-publish registry and GitHub artifact verification is recorded separately after npm and GitHub accept the release.
