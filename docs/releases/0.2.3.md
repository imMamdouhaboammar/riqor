# Riqor v0.2.3

## Plugin asset compatibility

This patch fixes plugin directory upload validation for square SVG branding assets

- `interface.logo` now points to `./assets/mark.svg`
- `interface.composerIcon` points to the same 128×128 square mark
- the 640×160 `assets/logo.svg` remains an optional horizontal wordmark and is no longer referenced by the plugin manifest
- plugin health now rejects non-square manifest SVG assets before packaging
- the root-layout ZIP fix from v0.2.2 remains unchanged
- all 101 native Codex agent role configs remain bundled
