# Riqor v0.2.2

Riqor 0.2.2 fixes Plugin Directory ZIP compatibility by placing the plugin manifest directly at the archive root

## Fixed

- `.codex-plugin/plugin.json` is now stored at the ZIP root instead of behind a `riqor/` wrapper directory
- Plugin archives remain deterministic and keep all 101 native Codex agent role files
- Added a regression test that rejects wrapped release archives and requires the root manifest layout

## Distribution

- npm package: `riqor@0.2.2` on `latest`
- Git tag: `v0.2.2`
- Plugin ZIP: `riqor-0.2.2+codex.<cachebuster>.zip`
