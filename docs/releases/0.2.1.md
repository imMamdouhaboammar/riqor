# Riqor v0.2.1

Release date: 2026-08-09
Channel: Stable

## Native Codex agents

Riqor now ships the repository's complete 101-agent Codex catalog as native TOML role configs inside both the Codex plugin and npm runtime

`riqor install` creates two Riqor-owned surfaces under `CODEX_HOME`:

- `riqor.config.toml`, an agent-only profile
- `riqor-agents/`, the 101 native role configs

`riqor codex` selects the `riqor` profile automatically when it is available. An explicit `-p` or `--profile` remains authoritative

The profile does not configure apps, MCP servers, or tools. Existing foreign paths are preserved rather than overwritten

## Install

```bash
npm install -g riqor
riqor install
riqor codex
```
