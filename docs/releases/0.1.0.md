# Riqor v0.1.0 Release Notes

**AI agents should prove the work**

Riqor v0.1.0 is the first public release of the Riqor agent verification runtime.

## Installation

```bash
npx riqor install
```

Or via Homebrew:

```bash
brew install imMamdouhaboammar/tap/riqor
riqor install
```

## System & Surface Inventory

- **Supported Platforms**: macOS (darwin), Linux.
- **Node Requirement**: Node.js >= 22 (zero Bun dependency for end users).
- **Codex Plugin Identity**: `codex-self-improvement@codex-self-improvement-dev` v0.2.0 (retained for baseline compatibility).
- **Command Aliases**: `riqor`, `codex-harness`, `cxh`.

## Boundaries & Security

- Riqor does not modify model weights or underlying model architectures.
- Riqor does not make AI model outputs deterministic.
- Hosted ChatGPT cloud conversations do not run local Riqor code in their cloud environment.
- Credentials and source contents are not stored in Riqor state.

## Verification & Release Gate Summary

- Unit & integration tests: 100% passed across all test suites.
- Tarball inspection: 0 forbidden files, 0 secret leaks.
- Homebrew formula audit & install test: passed with zero user config mutation prior to explicit `riqor install`.

## Disabling & Rollback

```bash
riqor uninstall
```
