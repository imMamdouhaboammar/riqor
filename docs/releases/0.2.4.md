# Riqor v0.2.4

## Marketplace specialist catalog

This release turns the Riqor Plugin Directory package into a portable specialist capability pack for ChatGPT and Codex

- exposes 101 generated specialist Skills derived from the canonical native agent catalog
- keeps all 101 native Codex agents and requires each one to load its exact paired Skill before execution
- adds deterministic agent-to-Skill mapping, content hashes, stale-generation checks, and a generated specialist index for `riqor-core`
- keeps the existing 11 Riqor workflow Skills, for 112 bundled Skills total
- adds no Apps, MCP servers, or tool configuration

## Offline adoption ledger

The local npm runtime can now report coarse adoption counters with `riqor adoption`

- local-only storage with a random local installation identifier
- active-day, session, agent-start, version, and explicitly observed Skill counters
- bucketed receipt export without the installation identifier
- `riqor adoption --reset` removes only the adoption ledger
- no Riqor analytics endpoint, hidden tracking pixel, or phone-home path
- public ChatGPT Marketplace install counts remain `unknown` when OpenAI does not expose them to the publisher
