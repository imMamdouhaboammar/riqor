# Riqor v0.2.0

Release date: 2026-08-09
Channel: Stable

## What changed

- Promotes the verified 0.2 feature line to the stable npm `latest` channel
- Reworks the GitHub and npm README around the core product value and a shorter path to first use
- Replaces the previous doodle mascot with a compact R verification mark and matching wordmark
- Adds plugin logo assets so the Codex marketplace presentation uses the same brand
- Keeps the zero-runtime-dependency npm package and Node 22 execution boundary

## Install

```bash
npx riqor install
```

Or

```bash
npm install -g riqor
riqor install
```

## Release contract

- npm package: `riqor@0.2.0` on `latest`
- Codex plugin: `riqor@riqor`
- Git tag: `v0.2.0`
- npm publication: authenticated maintainer terminal only
- GitHub release artifact: downloaded from npm and compared byte-for-byte with the release build before attachment

## Verification

Publication requires the repository suite, packaged runtime tests, plugin validator, plugin smoke test, tarball inspection, action pin verification, security checks, and post-publish registry verification to pass
