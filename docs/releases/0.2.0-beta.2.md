# Riqor v0.2.0-beta.2

Released: 2026-08-09
Channel: Beta prerelease

`0.2.0-beta.2` refreshes the public documentation surface and Codex plugin distribution metadata. The runtime behavior remains the `0.2.0` beta behavior documented in the previous release.

## What changed

- Added Divio-structured tutorials, how-to guides, reference pages, and explanation pages
- Refreshed the public README and documentation hub with explicit local-runtime and hosted-ChatGPT boundaries
- Refreshed the Codex plugin cachebuster so Codex can observe the current plugin source from the repository marketplace

## Release boundaries

This release remains on npm's `beta` dist-tag and must not replace `latest`. It does not publish a new Homebrew formula. Riqor remains local developer tooling and does not execute inside hosted ChatGPT conversations or change model weights.

## Verification

The machine-readable post-publish evidence is recorded in [`0.2.0-beta.2-verification.json`](0.2.0-beta.2-verification.json) after npm and GitHub accept the release.
