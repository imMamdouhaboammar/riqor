# Riqor Support

Riqor support is handled through the public GitHub repository. This is an open-source project and does not include a guaranteed response time or service-level agreement.

## Bugs and product support

Use GitHub Issues for reproducible bugs, installation problems, compatibility problems, documentation errors, and feature requests:

https://github.com/imMamdouhaboammar/riqor/issues

Before opening an issue, include the Riqor version, host surface such as ChatGPT or Codex, operating system when relevant, the exact command or workflow that failed, the expected behavior, and sanitized error output. Remove API keys, cookies, authentication tokens, private source code, personal information, customer data, and other secrets before posting.

## Plugin Directory issues

For ChatGPT/Codex plugin packaging or installation problems, include the plugin version and whether the issue occurs in ChatGPT, Codex, or both. Do not post account credentials or private workspace content. If a problem appears to be in the host platform rather than Riqor, the corresponding host support channel may also be required.

## Security vulnerabilities

Do not file a public issue containing exploit details, credentials, or sensitive vulnerability information. Follow the process in `SECURITY.md` for security reports.

## Documentation

Project documentation, release notes, and current source are maintained in this repository. When reporting a documentation problem, link to the exact file and section where possible.
