# Security Policy

## Reporting Security Vulnerabilities

We take the security of Riqor seriously.
If you discover a security vulnerability, please do not open a public issue.

Instead, please report security vulnerabilities using
[GitHub Private Vulnerability Reporting](https://github.com/imMamdouhaboammar/riqor/security/advisories/new).

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Response Timeline

We aim to respond to security advisory reports within 48 hours
and provide updates until resolution.
