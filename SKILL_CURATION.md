## Reproducible installation

```bash
bash scripts/install-curated-skills.sh
```

The script clones each primary source, checks out the audited commit, installs only the approved names with `--agent codex --copy -y --full-depth`, verifies the upstream hashes against `skills-lock.json`, applies `config/curated-skills.patch` inside an isolated staging repository, validates canonical content hashes, and replaces the active skill directory only after every check passes

A failed preparation leaves the current directory untouched

A failed replacement restores the previous directory from its temporary backup

`skills-lock.json` records source-package hashes generated by the Skills CLI

`config/skill-curation.json` separately records SHA-256 digests over sorted relative paths and file contents after curation

## Rejected from automatic harness paths

- `agent-kernel-ops` because it includes environment push, pull, and publish operations
- `antigravity-superpowers` because it is an umbrella instruction set with broad routing overlap
- `agency-reality-checker` because its workflow is overfitted to Laravel and visual website approval
- `agency-test-results-analyzer` because it introduces heavy statistical dependencies without a direct correctness gate
- `agency-workflow-optimizer` because it adds generic process-analysis dependencies without a bounded scenario need
- `aonios-agent` because it may send source or prompts to external model providers
- `apeiron` because it invokes broad orchestration and external integrations
- `test-driven-development` because the installed Superpowers plugin already supplies it
- `grill-me` because interactive design interrogation is outside runtime evidence paths

## Universal policy

- Never publish memory automatically
- Never let a curated third-party skill install additional hooks automatically
- Never start a daemon automatically
- Never modify environment vault state automatically
- Never send repository content to an external model without explicit approval
- Never run load against production automatically
- Never retain prompts, source contents, command output, credentials, personal data, or repository paths in harness state
- Treat skill output as guidance until independent evidence confirms it
